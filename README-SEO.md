## Финальные шаги (15-30 минут)

1. **Получить verification коды:**
   - Зарегистрировать сайт в Яндекс Вебмастере
   - Зарегистрировать сайт в Google Search Console
   - Добавить коды в `/lib/seo-config.ts`

2. **Обновить домен:**
   - Убедиться что домен `cersanit-shop.ru` (или временный) используется везде
   - После покупки домена `.ru` настроить редирект 301

3. **Запустить проект:**
   - `npm run build` - убедиться что нет ошибок
   - `npm run dev` - локально проверить что все работает
   - Деплоить на Vercel

## Результаты SEO оптимизации

### Для Яндекса
- Поддержка Cyrillic в fonts
- Robots.txt оптимизирован для Yandex
- LocalBusiness schema с русским языком
- Sitemap.xml для быстрой индексации

### Для Google
- Open Graph теги для соцсетей
- Product schema для товаров
- Breadcrumb schema для навигации
- Мобильная оптимизация

### Для ИИ помощников (Алиса, ChatGPT, Claude, Perplexity)
- Robots.txt явно разрешает индексировать AI ботам
- Четкая HTML структура (семантические теги)
- JSON-LD разметка для понимания контента
- Schema.org Organization + LocalBusiness для контекста
